

## OCR模型启动步骤：

#### 进入环境
```text
conda activate cnocr-env
```


#### 启动cnocr服务
```text
cnocr serve -p 8501
```


#### 启动日志：
```text
INFO:     Started server process [93521]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8501 (Press CTRL+C to quit)
```
