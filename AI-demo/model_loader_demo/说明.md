# 项目说明

### transformer01 
加载llm模型，使用transformer库加载模型，通过API使用模型。

#### 测试 API

你可以使用 curl 测试 API：

```bash
curl -X POST "http://localhost:8000/generate" \
     -H "Content-Type: application/json" \
     -d '{"prompt": "你好，请介绍一下自己", "max_tokens": 100, "temperature": 0.7}'
```
